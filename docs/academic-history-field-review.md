Reviewed 2026-11-08 against the legacy documentation, migration definitions and academic views, and the current domain models, migrations and write/read repositories; implementation status refreshed 2026-11-09. This is an implementation input and gap review, not a claim that the missing fields or event streams have been built. Apply the [event-sourcing direction](event-sourcing.md) and [architecture/retrofit order](event-sourcing-architecture.md) before expanding academic writes. The [development roadmap](development-roadmap.md) consolidates remaining work.

Current equivalency joins never repair missing earlier source evidence. Working drafts validate reference labels; immutable publications retain their original source restrictions, selected student requirements remain explicit, and recorded progress reviews preserve their frozen basis. Known exclusions affect group placement only; unknown source evidence stops allocation without changing awarded credit/GPA. No schema, journal, report or fabricated historical fact was added.

[Review-date course expiration](degree-audit-builder.md#course-expiration-at-a-progress-review) is now an optional published group policy, independent of age at pursuit start. Current/temporary progress uses one explicit evaluation date; recorded observations retain that exact date in their existing protected basis and validate consistency with the observation's as-of date. Calendar advancement can change fresh group placement without changing awarded credit, GPA or the earlier recorded result. No graduation date is inferred, and no event, row or earlier policy is backfilled.

Only actual detail/review decisions append person education events; request creation, owner replies and closure append no fabricated profile or academic fact. Closing follow-up does not verify educational credentials or decide admission. Existing person/account ownership, history and accepted retries remain separate and unchanged; no schema or report was added.

[Per-card credit-origin restrictions](degree-audit-builder.md#institutional-and-transfer-contributions-within-a-group) now express partial institutional/transfer requirements inside a mixed-source course group. Current publications retain optional card origins; earlier absent values remain unrestricted without backfill. [Per-card grade-point minima](degree-audit-builder.md#different-grade-minima-within-a-group) now retain exact optional thresholds in current course-group publications. Shared matching filters actual contributions before repeat allocation, without converting grading scales or borrowing eligibility from another tied attempt. Protected same-identity, identical-definition grading republications can be verified even when a transfer award is excluded from GPA. Earlier absent fields remain absent. Private ordinal/point explanations and frozen recorded-review reproduction preserve original rules and graded inputs after an attributed grade correction; existing academic awards and historical events remain intact. Publication uses the existing protected journal; no migration, report or historical backfill is added.

[Reviewed reinstatement with prior registered-credit corrections](registration-history.md#reinstate-with-a-corrected-registered-quantity) now restores the same tracked ungraded attempt while preserving its latest registered quantity. The protected existing academic event retains original/current quantities and correction count and verifies them against actual earlier corrections during replay; the academic attempted/earned amounts remain separate. Current load sees the restored quantity, earlier determinations/receipts and financial postings remain intact, and later academic source/grade changes still block restoration. No unknown history is inferred, and no schema, report or journal is added.

[Institutional comparison-policy publication and section inheritance](academic-credit-history.md#institutional-comparison-policy-and-section-inheritance) now retain rounding/cap definitions in the same protected journal. ## Avoiding duplication without losing history

The intended chain is **Course identity → published CourseVersion → Section identity/published SectionVersion → student attempt/award events → projections/documents**. These are proposed ownership boundaries, not new tables already created by this review.

Normalize shared definitions: subjects, departments/schools, academic/course levels, campuses, rooms, grading schemes and award classifications have stable ULIDs and retirement/version rules. Keep readable codes as business attributes rather than foreign-key identities. Only retain a section override when that offering genuinely differs from its selected course version.

A reference to an immutable version avoids copying an entire definition into every student row. A retained award-time title, credit value, grade policy input or issued-document snapshot is intentional evidence. Removing it merely because a current join can supply a value would destroy history. Conversely, GPA totals, seat counts and repeated composed identifiers are derived read models, not additional writable sources of truth.

Material corrections append amendments and preserve the earlier version. Institutional-ID changes continue resolving the current ID through the same person; they do not rewrite recorded historical documents or domain events. Historical identity snapshots are retained only where justified and protected by the appropriate retention/access policy.

## Implementation priorities and acceptance examples

Restore reference/classification and published definition fields together with the secure event foundation, then convert authoritative academic awards and registration. Every added historical field must reach its intended draft editor, validation, publication/snapshot/event contract, persistence, replay, authorized queries and relevant report/portal/transcript presentation. Adding a nullable column alone does not complete the capability.

The first vertical slices must prove:

- Renaming/reclassifying `MATH.101` or changing its credit policy creates a new published version. Students enrolled under the earlier version keep their original title, classifications, credits and applicable grade policy.
- Two sections of one course may use different instructional dates, delivery/meeting arrangements and fee components without duplicating editable course definitions. A student attempt retains the selected version and actual credits.
- Amending a grade preserves the original grade, who changed it, why, effective/recorded times and applicable policy; current projections rebuild to the amended result while a previously issued document remains reproducible.
- An early drop removes current academic/transcript projections and reverses the original course charge, while protected history remains retained. A late drop keeps the institutional grade/charge policy. A retake is a distinct academic and billing-term attempt.
- Program/cohort and term/level reports reproduce their historical scope after catalog, reporting-group or grading-policy changes. Corrections never invent missing past values; imported unknowns remain explicitly unknown with provenance.

This review intentionally creates no speculative schema or live-data conversion. Field restoration and event-sourcing conversion remain implementation work. No working database or student data was accessed or modified.


## Awarded course versus original offering

The [institutional course-correction workflow](academic-credit-history.md#correct-the-awarded-course) now distinguishes the current awarded course/publication from the original registration and offering definition. Its reasoned event preserves both identities in the existing academic-credit stream, updates current academic projections and leaves source instructional dates, grading, quantities, pursuit and charges unchanged. The existing course binding projection is reused. Transcript preparation and prerequisite/degree readers use the accepted corrected award, while repeat chronology verifies the original course, publication and term against the original offering. No current catalog edit can rewrite either accepted definition. Earlier unknown references stay unknown; reopening/reinstatement remains separate work.

### Enrollment-target follow-through

Versioned course defaults, audit enrollment and waitlist allocation remain separate scope. See [minimum enrollment targets](section-publication.md#minimum-enrollment-targets).
