Batch fees makes creating bills and adding student fees much easier than adding to each student one by one. You must have the `financial module` in order to generate student bills.

You can choose from three populations in order to create batch bills or add batch fees: by program, by major or by academic level. With each population, a student must have an active student program without an end date.

#### How it works?

Once you choose a particular population, term, and fees to be added, a bill will be created for each student in the particular population based on the academic term. If a bill for the term already exists for a student, then fees will be added to the current term’s bill instead of creating a new bill.
