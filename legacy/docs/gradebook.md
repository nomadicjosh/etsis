Professors can create assignments per course section and grade those assignments as well. Furthermore, each course section has its own gradebook. The instructions below shows you how the gradebook is organized.

#### My Course Sections Screen

1. Course Section Gradebook – The gradebook icon will only appear if one assignment exists for the course section.
2. Course Section Assignments
3. Final Grades

#### Course Section Gradebook

When viewing the gradebook for a particular course section, it will list all the students, the assignments and their grades. The heading for each assignment is the short name. Hovering over the short name reveals the full title of the assignment

#### Course Section Assignments

When viewing assignments for a particular course section, you have the option of performing two options depending on the situation:

1. View/Edit the assignment
2. Grade the Assignment – Clicking this icon will take you to a list of students where you will be able to submit a grade for each student for a particular assignment.
