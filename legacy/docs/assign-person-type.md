When creating a new person record, you should assign a person type. There are several users that may fall into more than one person type. Nevertheless, you should assign the person type with the highest authority. Below are a few examples to follow.

1. If a user is a student as well as a teacher, the \`Faculty\` person type should be assigned.
2. If a user is a teacher as well as a staff member, the \`Faculty\` person type should be assigned. However, you need to take into which function has the most work load in this case.

 The assignment of the person type is useful for running reports or saved queries.
