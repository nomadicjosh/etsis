When a student is enrolled into a course, a registration status is added to the registration. When viewing a student’s academic credits via the STAC screen, the registration status is shown in the status column (see figure 1). If the status is `A`, it means the student was registered into the course by a staff member. If the status is `N`, it means the student registered him/herself into the course. If the status is `W`, it means the student withdrew from the course. If the status is `C`, it means the course was cancelled. Or, if the status is `D`, it means the student dropped the course.
